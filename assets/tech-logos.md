# Technology logos

Website skill logos are stored in `public/tech/` and displayed as monochrome CSS masks. Labels remain readable if a mask fails to load. They are not used by either résumé renderer.

- Most SVGs: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), distributed under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
- AWS: [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/amazonaws.svg).
- Midtrans: the three-bar mark extracted from the [official logo](https://midtrans.com/assets/img/logo-blue.svg).
- Motion: [SVGL](https://github.com/pheralb/svgl/blob/main/static/library/motion.svg), sourced from [Motion](https://motion.dev).
- AI APIs is a general category, represented by the existing Lucide Workflow icon.

Brand names and marks belong to their respective owners.
